# Add a CSV datasource  
A CSV datasource is a yaml configuration file, whom conforms to [CsvDataSourceProperties](../../commons/src/main/java/org/open4goods/commons/config/yml/datasource/CsvDataSourceProperties.java). It bridges CSV containing datas on products into the platform (mapping CSV lines to [DataFragments](../../model/src/main/java/org/open4goods/model/datafragment/DataFragment.java).  
  
Please, refers to existing configuration for use as examples, we advise to get it as a starting point for any new CSV data source integration.
